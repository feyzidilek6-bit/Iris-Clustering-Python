# Iris Clustering Visualization – Python

A university Python project focused on exploring distance-based clustering using the Iris dataset.

## Technologies
- Python
- Matplotlib
- CSV data processing

## Project Features
- Loading and processing data from the Iris dataset
- Calculating distances between data points and predefined cluster centers
- Assigning data points to two clusters based on distance
- Visualizing the clustering results using Matplotlib

## How to Run
1. Install Python and Matplotlib.
2. Download `main.py` and `iris.csv` into the same folder.
3. Run the program using:

   `python main.py`

## Dataset
The project uses the Iris dataset, stored in `iris.csv`.
